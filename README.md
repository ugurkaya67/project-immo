# Project Immo

Application web d'agence immobilière développée avec :

- Next.js
- Prisma
- PostgreSQL (Neon)
- Vercel

Fonctionnalités :

- Authentification admin/client
- CRUD des biens immobiliers
- Filtres de recherche
- Fiche détaillée avec DPE/GES
- Déploiement CI/CD avec Vercel
